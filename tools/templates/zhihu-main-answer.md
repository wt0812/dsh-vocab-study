背单词工具我拆成四条路线说，前三条是市面上的主流选择，第四条是我自己在用的方案（**利益相关：下面那个插件是我写的**）。

**一、手机 App 系（主力，适合大多数人）**

这一档现在做得最成熟，代表是墨墨背单词、百词斩、不背单词、扇贝。

它们的核心差别在**复习调度算法**。墨墨用的是自研的 MMX 记忆算法，把每个词的记忆强度和复习间隔单独算，界面极简、没有花哨的图片，强项就是"记得牢"。百词斩走的是另一条路 —— 图片辅助 + 例句，上手快、门槛低，适合完全背不进去的人先建立习惯。不背单词和扇贝更偏"语境 + 例句"，有大量真实语料。

**选这类的前提**：你愿意每天专门掏手机、花 15 分钟以上。它们都做得很好，这是最稳的选择。

**二、Anki 系（适合愿意折腾的人）**

Anki 是开源的间隔重复工具，插件生态庞大，但**上手成本最高** —— 你要自己找牌组、自己配参数、自己维护。

算法上它已经换到 **FSRS**，学界讨论很多，调度比老版本准得多。如果你追求"完全按我自己的记忆曲线来"，并且不介意花一个周末配置，Anki 是最强的。反过来，如果你只想背个四六级，用它是杀鸡用牛刀。

**三、键盘拼写系**

代表是开源的 **Qwerty Learner**。它把背单词和打字练习合在一起 —— 通过键盘敲单词来记，主要面向雅思这类需要拼写准确的场景。

这类工具的好处是**手不用离开键盘**，坏的方面是它侧重拼写，对"认识但不会拼"的词帮助有限。

---

**四、我自己的方案：把词卡塞进你已经在用的那个界面里（利益相关，我是作者）**

上面三条路线的共同点是：**你都得离开手头的事，专门去"背单词"。**

我做的是一个 **DeepSeek Harness（DSH）插件**，叫 **dsh-vocab-study**。思路很简单：我用 DSH 干活的时候，等模型输出那几十秒通常就那么放着 —— 与其放着，不如背几个词。

它长在输入框旁边，平时是一颗小胶囊。点开是一张词卡：正面只有单词和音标，翻面给释义和例句，然后用键盘 `1` `2` `3` 自评「忘了 / 模糊 / 会了」。**手不用离开键盘。**

几个具体的：

- **零运行时依赖**：`dependencies` 是空的，客户端产物单文件 3,003,897 字节（约 2.86 MB），绝大部分是词库
- **断网也能背**：六本内置词库共 **29,841** 词（四级 / 六级 / 考研 / 雅思 / 托福 / GRE）
- **数据一个字节都不出本机**：只写浏览器 localStorage，不发任何网络请求
- **不用它的日子它什么都不做**：面板不会自己弹出来 —— 这是刻意的，我不想让背单词插件抢注意力
- **进度页敢回答「接下来 30 天还剩多少」**：按记忆强度排期算出来的，不是装饰用的百分比。另外有个判定叫「已收服」，条件是记忆强度 ≥ 0.9 **并且**在辨词题里答对过 —— 只在词卡上点「会了」不算
- **8 个套件 / 400 项断言全绿**，MIT 开源

**哪些人不该装，我直说：**

- **它只能在 DSH 里用。** 你不用 DSH，这个插件对你没有任何意义 —— 直接看上面前三条路线
- **没有真人发音。** 音标朗读走的是系统 TTS，音质取决于你的系统，**不是真人朗读**
- **没有词根、没有助记、没有花哨的记忆法。** 有个「让我记住它」按钮，但它是**用词库里真实存在的字段**（词根/例句/搭配/易混词）重组成一句话，**不是 AI 编的** —— 宁可少给，也不给你编一个听着很美的假记忆法
- **没有手机版，没有云同步。** 数据就在那台机器的浏览器里，换设备等于重来
- **装完必须完整退出 DSH 再打开。** DSH 的客户端模块清单在启动时就扫描完了，运行中装插件浏览器里不会长出来（这个我实测确认过）
- **只有 6 本主流词库**，不是"覆盖全宇宙单词"

**装法**：DSH 的「设置 → 插件 → Add plugin」里搜 `dsh-vocab-study`，或者：

```
dsh plugin --profile web add dsh-vocab-study
```

注意是 `--profile web`，写成 `desktop` 会报错（那个 profile 由 Electron 应用独占管理）。
