0.3.3：面板不再被一个巨大黑圆盖住

> 纯界面修复，学习记录、生词本、连击、设置一个都没动，升级即用。

### 一句话说清这版干了什么

完成一轮停在「这一轮走完了」时，面板中下部会突然出现一整块纯黑的圆（右侧还连着一段弧），
底部统计文字被挤到最左边，横向滚动条也冒出来 —— 看着像插件崩了。
其实没崩：是**样式表没生效**时，图形退回了 SVG 的默认值。这版把这个失效模式修掉了。

### 根因

进度环和记忆曲线这两个 SVG 图形的尺寸和填充，全都只写在 CSS 里：

- 外层 SVG 元素没写宽度和高度 → 撑满父容器；
- 圆元素没写 `fill="none"` → 用 SVG 默认的**黑色填充**。

两者一起缺，68px 的进度环就放大成盖住半块面板的黑圆。

样式表会不会在不由面板决定 —— 宿主热重载、面板被搬进 ShadowRoot、样式标签只剩空壳都可能发生；
旧代码只判断文档里有没有那个样式标签，有就直接返回，于是面板一路裸奔。

### 修法

- 进度环和记忆曲线的 SVG **自带**尺寸与无填充属性。属性比 CSS 弱，样式正常时仍由 CSS 决定，
  样式不在时最差只是留个空位 —— 不会再出黑块。
- 样式注入改成按面板**实际所在的那棵树**注入（支持 ShadowRoot），认出空壳样式标签后移除重注入。
- 每次渲染都确认一次样式，丢了能自愈。

复现方式固化进测试 `test/bundle-audit.test.mjs` 第 10/11 节：关掉插件样式表后截图对照。
