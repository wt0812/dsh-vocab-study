0.3.1：眼熟小组件 + CI 自检修复

> 这一版是界面小功能 + 工程修复。学习记录、生词本、连击、设置全都不受影响，升级即用。

### 一句话说清这版干了什么

背完一轮后，在按钮区和数据带之间新增一个「眼熟小组件」，自动轮播你今天已经背过的词（单词 + 音标 + 释义），8 秒切换，不交互、不计分。左侧边显示默认关闭，可在「设置 → 眼熟小组件」里勾选开启。

同时把 0.3.0 发布后连红三天的 CI 修好：根因是构建期守卫的自检脚本自己写了一份「代码 / 非代码」分离器，把数据文本和正则字面量误判成悬空引用。现在收敛成唯一实现 `tools/lib/dangling.py`，构建期守卫和自检脚本都调它。

### 眼熟小组件

- **数据源**：今天已经背过（答过题）的词，不会把没背的生词提前塞给你。
- **位置**：
  - 插件面板中间会**始终显示**，位于「再背一轮 / 再来几个新词 / 换词库」按钮下方、3/3 进度环和数据带上方。
  - 左侧边显示默认**关闭**，在「设置 → 眼熟小组件」里勾选「在左侧边显示」才会出现，避免和你侧边栏已有的账户/余额/更新信息冲突。
- **行为**：8 秒自动切换；右上角可临时关闭一次。

### CI 修复

- `tools/verify-dangling-guard.mjs` 与构建期守卫共用 `tools/lib/dangling.py` 的屏蔽器，正确识别注释、字符串、模板串、正则字面量。
- 本机打包前也会跑一遍自检，不再只依赖 CI。

### 一句提醒

客户端产物在 DSH 启动时加载，**升级后要完全退出 DSH 再打开**才能看到新界面。
