卡片背面多了**词根词缀**，覆盖率从 **25% → 48%**。

产品负责人原话：「词根词源太少了，大部分都是没有的，只有个同族词的折叠卡，这不对。」
他判断得对 —— 原来那份词根数据只有 **611 条**（一份语言学目录），
`spect`、`graph`、`phon`、`bio`、`chron` 这些最常见的词根**一条都没有**。
25% 是源数据的天花板，不是解析漏了。

> **重要变更**：词根数据从「只靠 ECDICT 611 条」升级成「ECDICT + 手写标准构词法表」，
> 覆盖率翻倍；但仍然**约一半词没有** —— 没有可信结构时这一块**整块不显示**，绝不硬猜。

## 新功能

- **卡片背面「词根词缀」**（默认展开，一行）：
  `前缀 dis(分离) · 词根 tribut(给予、分配) · 后缀 -ion(动作、状态)`
- **手写标准构词法表**：前缀约 100 条、后缀约 90 条、词根约 190 条，
  专补 ECDICT 缺的高频词根（`spect` / `port` / `tract` / `fer` / `duc` / `tribut` / `gest` / `tain` / `sorb` / `pect` / `und`）
- **严格切分器**：所有「前缀 × 后缀」组合都试一遍，选词根最长的那条；
  词根两侧多出来的字母必须能被词缀解释得通，否则判为切错

前两个版本叫「词根词源」，只报一个词根；现在真的会拆前缀和后缀，所以改名**词根词缀**。

## 修复

- `sider` 原来标「坐」→ 是**星**（`consider` = con + 观星）
- `remind` 原来被切成 `re + min(小)` → 现在不乱拆（`mind` 本身是词就不该再往下切）
- `comity` 原来被切成 `co + mit(送)` → 现在只报后缀 `-ity`
- 词根右侧残留一个字母以前一律放过，现在只放行「词根 + 末尾 e」（`tribute` 这种）
- **「上周回顾」周报口径**：原来用 `now()-7天` 却写「本周」，「最长连续」读历史值、
  诊断句硬编码「今天」。现在只在**周一**出、窗口是**上一自然周**、最长连续按该周内算
- 热力图标题「这半个月」→「最近三个半月」（数据实际是 15 周 = 105 天）

## 诚实边界（不藏着）

- **约一半词没有词根词缀**：短词、法语借词、日耳曼源词（`windy` / `momentum` /
  `abeyance` / `bullion`）本来就没有拉丁、希腊词根可拆。这些词整块不显示，只留同族词与搭配
- 随机抽 **40 条**人工核，**明确错 2 条**（`equator` 误判成 `-or`「…者」、`capsize` 误判成 `cap + ize`），约 95%
- 数据来源：ECDICT `wordroot.txt`（MIT 许可）+ `tools/morph-table.mjs` 手写表，
  第三方许可见 `docs/third-party/`
