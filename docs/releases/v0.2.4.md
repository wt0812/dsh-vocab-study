一个打包修正：**npm 包里不再发 `test/`**。之前发出去但没带源码，别人装完跑测试必然拿到一片假红。

> **重要变更**：**`test/` 从 npm 包里移除。** 之前 `test/` 会随包发布，但包里没有源码 —— 别人 `npm test` 会看到 8 个套件里红 5 个。
> 这不是他们的问题，是包的问题：**一个必然跑不起来的测试，比没有测试更坏**，它会让人以为你的代码是坏的。
> 仓库里的 `test/` **照常保留**，`npm test` 在克隆下来之后仍然完整可用。

## 修复

- npm 包不再包含 `test/` —— 它必然跑不起来，只会得到假红

## 其他改动
