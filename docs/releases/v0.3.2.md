0.3.2：修复换词库后设置页状态行重叠

> 界面小修，学习记录、生词本、连击、设置全都不受影响，升级即用。

### 一句话说清这版干了什么

0.3.1 新增「眼熟小组件」后，有用户发现**换词库后设置页的词库状态行会字叠字**，前半段被压到和下一行重叠。
这版修了这个渲染 bug。

### 根因

设置页的 `.vs-body` 是纵向 flex 容器，`.vs-collection-status`（换库成功/失败那行小字）是它的 flex item。
之前为了“空时不占位”，给状态行写了 `min-height: 0`，结果面板高度紧张时该行会被 flex 布局压到 0 高度，
文字直接溢出盖到下面的 `.vs-sub` 和「眼熟小组件」标题上。

### 修法

- `.vs-collection-status`：`min-height: 0` → `auto`，加 `flex-shrink: 0`。
- `.vs-sub`：也加 `flex-shrink: 0`，并把 `margin-top` 从 2px 提到 8px，视觉上更舒展。

客户端产物在 DSH 启动时加载，**升级后要完全退出 DSH 再打开**才能看到修复。
